espc-model-repo

One half of one model: the US Navy ESPC-D-V02 currents, at the surface, at 50 m, and depth-averaged to three caps, for the C4PO ocean map. The scalar fields off the same run — temperature, salinity, height and sea ice — are published by espc-model-fields-repo, split from these because the vector tiles are what cost bytes.

The name is a legacy one. Under the convention every model follows now this would be espc-model-currents-repo; it was not renamed because this URL is a live origin, and GitHub Pages does not reliably redirect a renamed project site.

It is not a public API. The files under map/ exist to be read by the map, and their layout is that map's contract.

What is fresh, what is held, and which roots this origin serves: status/status.json. The run's intent and outcome sit beside it as plan.json and receipt.json.

How it works, and why it holds no code of its own: the repository README.
