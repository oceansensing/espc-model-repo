# espc-model-repo

The US Navy ESPC-D-V02 currents, as gridded data for the oceansensing.org
ocean map: at the surface, at 50 m, and averaged over the top 200, 350 and
1000 m. The name is a legacy one: this is the model's currents repository, and
`espc-model-fields-repo` publishes the scalar fields from the same run.

Updated three times an hour, when the model has a newer hour.
